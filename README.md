# 🎬 DAMITV m3u8 Extractor

Estrae link m3u8 da DAMITV per usarli nel tuo player IPTV preferito.

## 📦 Installazione

```bash
# 1. Clona o scarica il repository
git clone https://github.com/tuo-user/damitv-m3u8-extractor.git
cd damitv-m3u8-extractor

# 2. Installa le dipendenze
npm install

# 3. (Opzionale) Crea file .env
cp .env.example .env
# Modifica le variabili se necessario
